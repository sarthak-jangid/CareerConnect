# 🚀 CareerConnect

CareerConnect is a full-stack web application that enables users to connect, share posts, and manage their professional profiles — similar to a mini LinkedIn-style platform.

---

## 🌐 Live Demo

🔗 https://careerconnect-app.vercel.app

---

## 📌 Features

* 🔐 Secure Authentication (JWT + Cookies)
* 👤 User Profile Management
* 📝 Create, Edit & Delete Posts
* 📷 Image Upload using Multer
* 📄 PDF Generation Support
* 🔔 Toast Notifications
* 🌍 RESTful API Integration

---

## 🛠️ Tech Stack

### Frontend

* Next.js
* React.js
* Redux Toolkit
* Axios
* React Toastify

### Backend

* Node.js
* Express.js
* MongoDB (Mongoose)

### Tools & Libraries

* bcrypt (password hashing)
* cookie-parser
* multer (file uploads)
* pdfkit & pdf-creator-node

CareerConnect/

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/sarthak-jangid/CareerConnect.git
cd CareerConnect
```

---

### 2. Setup Backend

```bash
cd backend
npm install
npm run dev
```

---

### 3. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file inside `backend/`:

```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
